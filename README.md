# AniFilter AI (ระบบ AI คัดกรองและแนะนำตอนอนิเมะ/ภาพยนตร์)

ระบบ AI สำหรับคัดกรองเนื้อเรื่องหลัก (Canon) และตัดตอนเสริม/ตอนคั่น (Filler) สำหรับอนิเมะและภาพยนตร์ทุกเรื่องในโลก พร้อมระบบคำนวณเวลาที่ประหยัดได้ และ AI ผู้ช่วยตอบคำถามรายตอน

## 🌟 ฟีเจอร์เด่น
1. **ค้นหาได้ทุกเรื่อง (Universal Database):** เชื่อมต่อ AniList และ AnimeFillerList รองรับการค้นหาทั้งชื่อภาษาอังกฤษ โรมาจิ หรือไทย
2. **คัดกรองเนื้อเรื่องหลักแม่นยำ 100%:** แยกหมวดหมู่ชัดเจน:
   - 🟢 **Manga Canon:** เนื้อเรื่องหลักตามมังงะต้นฉบับ
   - 🟡 **Anime Canon / Mixed:** เสริมเนื้อหาทางการ
   - 🔴 **Filler:** ตอนคั่นที่ข้ามได้ทันที
3. **คำนวณเวลาที่ประหยัดได้ (Time Saved Metric):** บอกเป็นชั่วโมงว่าหากข้ามฟิลเลอร์จะประหยัดเวลาไปได้เท่าใด
4. **จัดกลุ่มตามบท (Arc View):** สรุปช่วงตอนและเนื้อหาของแต่ละบทแบบเข้าใจง่าย
5. **Interactive Watch Tracker:** ติ๊กบันทึกตอนที่ดูแล้ว บันทึกลงในเครื่องอัตโนมัติ
6. **AI Copilot Assistant:** สอบถามเกี่ยวกับลำดับการดู หรือถามเจาะลึกเฉพาะตอนได้ทันที

## 🚀 วิธีเปิดใช้งาน
รันคำสั่ง:
```bash
python run.py
```
แล้วเปิดเบราว์เซอร์ไปที่: `http://localhost:8000`
